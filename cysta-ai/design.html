Открытые решения владельцу

  1. Модель подписки — решено Weekly $7.99 с 7-дневным триалом (по умолчанию) и Annual $39.99 без триала.
  2. Онбординг — выбор в симуляторе A: тап «что привело» → 2 экрана по теме → готовый ответ с источниками → пейвол. B: 4 визуальных экрана → пейвол (как Hepatica). В обоих ни ввода, ни камеры до цены.
  3. Доли плательщиков — гипотеза Данных RevenueCat / ASC пока нет, оценки Master v2 остаются с пометкой.
  4. Новые функции V2 — на утверждение Подготовка к визиту, PCOS-профиль, «Можно ли мне это?», цикл диапазоном. Остальное — в бэклог (раздел «Новое»).
Порядок спринта: аудитория → запросы и первая победа → онбординг (4 шага) → пейвол (отдельная ветка) → Today и табы → уведомления → аналитика → дизайн и ассеты через Codex → скриншоты (отдельная ветка).
