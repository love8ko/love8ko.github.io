# Дизайн Sakinah для обучения

Рекомендация после нового прогона: сохранить **Mihrab Heritage** и использовать вариант **B с адаптацией для чтения**. Новое оформление рабочей страницы не заменяет дизайн-систему продукта. Главную возвращаем к структуре Two Sparrows по отдельному указанию основателя.

## Что сравнивали

- A — исходная Mihrab Heritage, перенесённая на экран урока: крем/изумруд днём, индиго/песок ночью, перевод 16 px курсивом, тонкая арка у заголовка.
- B — те же цвета и арабская типографика; перевод 18 px прямым начертанием, обычный разделитель вместо арки у заголовка, визуальная связь выделенной фразы со значением.
- C — новое оформление страницы: светлая бумага, зелёные кнопки и шалфейные поверхности, заголовки sans, без тёмной палитры.

Тексты, источники, функции, цена и порядок действий одинаковы. Сравнивали сочетания визуальных решений, поэтому нельзя приписать весь результат одному увеличению кегля.

## Практическое решение

Сохраняем исходные токены Paper и Mihrab, песочно-золотую основную кнопку, serif-заголовки и Amiri Quran для арабского. В учебном экране предлагаем прямой крупный перевод, отчётливую связь выбранной фразы с разбором и минимум декоративного обрамления вокруг текста. Источники остаются видимыми во всех вариантах.

Ночная тема следует системному выбору. Прежняя идея переключать тему по времени молитвы относилась к утилитарному продукту; для обучения она не требуется.

Это рабочая рекомендация по разрешённому основателем сравнению. Окончательную композицию учебных экранов ещё нужно проверить на устройстве, с увеличенным текстом и реальными пользователями. Отдельный новый бренд на основании этого прогона не нужен.

## Метод и пределы

16 синтетических персон, 4 когорты внутри текущей узкой аудитории. Равные веса для проверки устойчивости, не оценка рыночных долей. Два порядка в каждом из двух раундов. Версия модели `jev-1.13.0`. Имена вариантов и история выбора скрыты от модели. Опция «нет подходящего» включена.

Jev видел текстовые описания, не изображения. Это не исследование людей и не измеренная конверсия. Макеты на публичной странице — визуализация сравниваемых описаний для основателя; качество глифов, вёрстки и контраста проверяется отдельно. Полноценная панель Fable по скриншотам в этот прогон не входила.

64 запроса, 544 структурированных ответа, 135 308 входных и 11 168 выходных токенов. Расчёт по опубликованной цене $0.042/M входных токенов: **$0.00568**, не счёт провайдера. Повторных платных раундов после финальной пары не запускали.
